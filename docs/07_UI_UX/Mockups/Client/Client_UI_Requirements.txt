## 3. Client browser

### 3.1 Search, filters, and creation

- The client_search occupies its own row.
- Set initial client_search field to blank
- If client_search results are found, then populate the Client List with returned client information
- If client_search results are not found, then an display a user message

- Client Type and Status filters sit side by side beneath it.
- Default client_type_filter to "All Types" and displays all clients
- If client_type_filter "Individual" is selected, then display only individual type clients in the Client table
- If client_type_filter "Organization" is selected, then display only organization type clients in the Client table

- Default status_filter to "All Statuses" and displays all clients
- If status_filter "Active" is selected, then display only clients with a status = "Active" in the Client table
- If status_filter "Inactive" is selected, then display only clients with a status = "Inactive" in the Client table


- Create Client spans the available pane width beneath the filters.
- Clicking create_client`initialize Client Workspace for a new client and sets the cursor focus


### 3.2 Client table — screenshot sample data

- Columns appear in this order: `Name / Organization`, `Type`, `Status`.
- The first column uses a bold name on line one and a muted email on line two.
- Header separators divide the columns.
- Rows have horizontal separators.

- On form initialization, the Client table will initialize to all client records; sorted by name ASC
- Selecting a Client table row will populate the Client detail with selected client information
- Row selection is by the highlighted row and matching detail pane.
- Each column will have the ability to sort the column in ascending and descending order
- The Client table will prevent multi-selection of rows
- Selection from Client table when Client detail has dirty data will result in a message of unsaved client information, with options to continue.
- If option selection is to discard unsaved changes, then the selected Client table information will populate the Client detail without saving the existing data.
- If option selection is to saved the changes, then the selected Client table information will be cancelled and the Client detail will retain the unsaved data.
